# Анализ текущей системы и целей миграции 
### Текущее состояние:
* Монолит на базе 1С, Excel и локальных серверов.
* Ручные процессы (операции с файлами).
* Невозможность масштабируемости как единой системы
* Проблемы с безопасностью и консистентностью данных. 
### Цели миграции:
* Соответствие росту нагрузки
* Автоматизация процессов
* Соответствие требованиям 152-ФЗ
* Повышение удовлетворенности клиентов
* Накопление статистических данных для развития

# Проблемы и решения

## Интеграция
|Проблема|Пути решения|
|-|-|
|Неучтенные особенности работы подсистем |Провести аудит использованных решений<br>Интеграционное тестирование|
|Ошибки реализации модулей интеграции|Интеграционное тестирование<br>Трассировка и мониторинг обмена|
|Ошибки взаимодействия подсистем |Трассировка и мониторинг обмена|
|Неоправданно сложное внедрение готовых подсистем |Пересмотреть необходимость использования, поискать альтернативы, найти специалиста по данной системе|
|Проблемы совместимости форматов данных|Интеграционное тестирование|

## Производительность
|Проблема|Пути решения|

|Недостаточная пропускная способность шлюзов |Нагрузочное тестирование, расчет ожидаемой нагрузки, горизонтальное масштабирование|
